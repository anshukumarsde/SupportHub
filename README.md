# SupportHub

SupportHub is a beginner-friendly customer support app. A support team can
use it to look at customer questions and see whether each question is still
open, being handled, or finished.

This is the first version of the app. It is currently a screen-only demo:
the tickets are example data written directly in the code. The app does not
save new tickets or use a database yet.

## How the app works

When you open SupportHub:

1. Next.js loads the page in `supporthub/app/page.tsx`.
2. The page creates a small list of example tickets.
3. The page sends that list to `TicketTable`.
4. `TicketTable` displays each ticket in a table.
5. Tailwind CSS provides the colors, spacing, borders, and layout.

In simple terms, `page.tsx` decides **what information the page has**, and
`TicketTable.tsx` decides **how the ticket list looks**.

## What you can see

- The total number of tickets
- The number of tickets that still need an answer
- The number of finished tickets
- Recent customer questions
- The person who asked each question
- The current status of each question
- The priority of each question

## Project folders and files

The actual Next.js project is inside the `supporthub` folder:

```text
SupportHub/
├── README.md
└── supporthub/
    ├── app/
    ├── package.json
    ├── package-lock.json
    ├── tsconfig.json
    └── ...
```

### Files in `supporthub/app`

| File | What it does |
| --- | --- |
| `page.tsx` | Builds the main dashboard. It contains the example ticket list and the summary numbers. |
| `TicketTable.tsx` | A reusable React component that displays tickets in rows and columns. |
| `layout.tsx` | Provides the shared page wrapper, browser title, fonts, and global CSS connection. |
| `globals.css` | Loads Tailwind CSS and contains styles that apply across the app. |
| `favicon.ico` | The small icon shown in the browser tab. |

### Configuration files

| File | What it does |
| --- | --- |
| `package.json` | Lists the libraries the app uses and the commands available through npm. |
| `package-lock.json` | Records the exact versions of installed libraries so installs are consistent. |
| `tsconfig.json` | Tells TypeScript how to check the project code. |
| `next.config.ts` | The place for Next.js settings. It is mostly empty because the app does not need custom settings yet. |
| `postcss.config.mjs` | Connects Tailwind CSS to the build process. |
| `eslint.config.mjs` | Contains rules used to find common code problems. |
| `next-env.d.ts` | Generated TypeScript information used by Next.js. Do not edit this file manually. |
| `.gitignore` | Keeps generated folders and private files out of Git. |

The `node_modules` folder contains downloaded libraries. It is created by
`npm install` and should not be committed to Git. The `.next` folder is also
generated by Next.js when the app runs or builds.

## Requirements

Install [Node.js LTS](https://nodejs.org/). npm is included with Node.js.

Check that Node.js and npm are available:

```powershell
node --version
npm --version
```

## Run the app for the first time

Open PowerShell in the repository root, then run:

```powershell
cd .\supporthub
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in a browser. The page
will update automatically when you edit the code.

To stop the app, press `Ctrl+C` in the terminal.

## Useful commands

Run the code checker:

```powershell
npm run lint
```

Create a production version:

```powershell
npm run build
```

Start the production version after building it:

```powershell
npm run start
```

## Making a simple change

To change the example tickets, open:

```text
supporthub/app/page.tsx
```

Find the `tickets` list and edit a ticket's subject, customer, status, or
priority. To change the table columns or how a status looks, open:

```text
supporthub/app/TicketTable.tsx
```

## What will be added later
