# SupportHub

A simple customer support ticket dashboard built with Next.js.

## Run the app

```powershell
cd .\supporthub
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Main files

- `supporthub/app/page.tsx` - dashboard page and sample tickets
- `supporthub/app/TicketTable.tsx` - reusable ticket table
- `supporthub/app/layout.tsx` - page metadata and layout
- `supporthub/app/globals.css` - global styles
